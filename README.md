# Vignan Faculty Tools

A better, simpler way for Vignan faculty to access everyday academic tools.

The official ECAP portal is often confusing and feels outdated. Since it remains the required platform, I built **Vignan Faculty Tools** to make the faculty experience a little easier.

This project is my attempt to fix what I can, improve usability, and make common faculty workflows less frustrating.

> [!WARNING]
> **Read-only website:** Vignan Faculty Tools only displays information. It does not write, modify, update, or delete anything in your faculty account. Your official faculty account and ECAP records remain unchanged.

## Why This Exists

ECAP is still the official system. Replacing it is not the goal. Making the experience around it better is.
